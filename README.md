# Stillroom

A quiet focus space with a Pomodoro timer, short and long breaks, four photographic rooms, adjustable ambient rain and room tone, and session history saved in your browser.

Open index.html in a modern browser, or serve it with any static web server. The website is packaged as one self-contained HTML file with embedded styles, scripts, and room images.

Sessions stay on your device. Clearing browser data removes history. Sound starts only when enabled.
